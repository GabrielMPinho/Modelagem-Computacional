# Modelagem Computacional

Repositório de estudo da matéria **Modelagem Computacional** (faculdade). Aqui fico minhas notas, exercícios e materiais de apoio, convertidos das aulas em formato Markdown para estudo rápido.

## Conteúdo

| Pasta / Arquivo | Descrição |
|---|---|
| `Revisao_Python/lista.ipynb` | Exercícios de revisão de Python (Jupyter Notebook) |
| `serie_taylor/` | Aula 3 — Série de Taylor (PDF, notas `teoria.md` e gráficos) |
| `derivacao_numerica/` | Aula 4 — Derivação Numérica (PDF e notas `teoria.md`: diferenças finitas progressiva/regressiva/centrada, com cálculos passo a passo e denominadores Δx explícitos) |
| `instrucao_agente.md` | Instruções para transformar PDFs de aula em material de estudo Markdown |

## Como usar

- Abra os notebooks (`.ipynb`) no **Jupyter Notebook** ou **VS Code**.
- As notas de estudo (`teoria.md`) são autocontidas e renderizam em qualquer visualizador de Markdown.
- Os gráficos são embutidos como base64 nos arquivos `.md`, então não precisam de arquivos de imagem separados.

## Estrutura planejada

Cada aula estudada segue o padrão: pasta da aula → `teoria.md` (material completo passo a passo) + notebooks com os códigos e gráficos.
